# EventTicketingApp

EventTicketingApp is a full-stack event ticketing web application that allows users to discover events, register for accounts, purchase event tickets, receive digital tickets with QR codes, and have their tickets validated at events.

Organizers can create and manage events, configure ticket types, view event information, monitor ticket sales, and validate attendees.

---

## Features

### For Attendees

- User registration and login
- Select account type during registration
- JWT-based authentication
- Browse published events
- Search and filter events
- View event details
- View available ticket types and prices
- Purchase tickets
- View order information
- Complete payment through the application payment flow
- Receive generated digital tickets
- View ticket numbers
- Access ticket QR codes
- View personal tickets and profile
- Use tickets for event check-in

### For Organizers

- Organizer account registration
- Organizer dashboard
- Create events
- Edit events
- Configure ticket types
- Set ticket prices and quantities
- Set ticket sale start and end dates
- Publish/manage events
- Cancel events
- View managed events
- Monitor tickets sold
- Validate attendee tickets
- Check in attendees
- View sales and event analytics

### API Documentation
